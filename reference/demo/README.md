# CampusConnect

Campus placement management demo (Student, Department SPOC, Placement Admin).

## Run
1. Unzip this folder.
2. Double-click `index.html` to open it in Chrome, Edge or Firefox.
   (Or run `python -m http.server 8000` in this folder and open http://localhost:8000)

No install or build step needed. Data is saved in your browser (localStorage).
Use "Reset demo data" in the Admin menu to restore the sample data.
Fonts load from Google Fonts when online; the app still works offline with fallback fonts.
